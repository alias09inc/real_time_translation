# 翻訳精度改善レポート(要約版)

作成日: 2026-09-03

もともと「①専門用語に弱い」「②発音の聞き取りミス」「③会話の区切りが短すぎて翻訳が失敗する」という3つの課題を調べていました。今回、しばらく前に別のチームが行っていた大規模な検証結果が手元に入ってきたので、それを踏まえて状況を整理し直しました。

## 結論だけ知りたい人向けのまとめ

| 課題 | 状況 |
| --- | --- |
| ① 専門用語に弱い | **解決済み**。事前に資料から専門用語を読み込ませる仕組みがすでにあり、効果も数字で確認できている |
| ② 発音の聞き取りミス | **原因は特定・分析済み**。追加検証は行ったが、聞き間違いを直接減らせるかはまだ結論が出ていない |
| ③ 区切りが短すぎる | **大きな原因(バグ)は1つ見つけて直した**。修正後に正式な検証も実施済み |

## ① 専門用語に弱い問題

講演やスライドの資料を事前に読み込ませて、専門用語や固有名詞を自動でリスト化しておく仕組みが、すでに実際に動く形で用意されていました。

75分の講演動画を使って「このリストがある場合」と「ない場合」で比較したところ、リストがある場合は専門用語の翻訳が100%正しく対応できていました。リストがない場合は、たとえば「Arena Score」という固定の言葉を、意味を無視して「アリーナ(競技場)スコア」と訳してしまうなど、業界で使われている正しい言い方から外れてしまう例が見られました。

つまり、事前に資料さえ渡しておけば、専門用語まわりの問題はほぼ解決できることが数字で裏付けられました。

## ② 発音の聞き取りミス

音声認識(人の声を文字にする部分)が、専門用語を似た音の別の言葉に聞き間違えてしまう問題です。

たとえば「language model(言語モデル)」という専門用語が、「laundry model」や「launching model」のような、まったく違う意味の言葉に聞き間違えられるケースが、別々のタイミングで2回確認されました。同じ言葉が繰り返し聞き間違えられていることから、この種の専門用語は音声認識にとって構造的に苦手な部類だとわかります。

さらに厄介なのは、聞き取りの「自信度」が高い(=システム自身は自信満々)にもかかわらず間違っているケースが大半だったことです。つまり「自信度が低いものだけ人がチェックする」というやり方では、この種の間違いはほとんど見逃されてしまうことが確認されました。

現状、この問題を完全に防ぐ方法はまだ見つかっていません。①の「事前に専門用語を読み込ませる仕組み」が聞き間違い自体をどれくらい減らせるか、実際に音声で試してみたところ、今回試した区間(比較的聞き取りやすいナレーション)では明確な差は出ませんでした。ただしこれは「効果がない」という結論ではなく、たまたま今回試した部分が音声認識にとってそれほど難しくなかったため、と考えられます。実際に聞き間違いが起きているような難しい区間で改めて試すのが次のステップです。

## ③ 区切り(チャンク)が短すぎて翻訳が失敗する問題

調査の過程で、翻訳する文章の区切り方に関わる重大なバグが見つかりました。本来は1つの発言としてまとめて扱うべき内容が、システムの内部処理のせいで複数の断片に分かれて二重・三重にカウントされてしまっていたのです。

このバグを修正したところ、同じ2分間の音声で数えていた区切りの数が、修正前の40個程度から21個程度(ほぼ半分)まで減りました。つまり、これまで「区切りが短すぎる」と感じていた原因の相当部分は、このバグによる水増しだった可能性が高いということです。

このバグ修正より前に行っていた「区切りの長さをいろいろ変えて試す実験」は、このノイズが混ざった状態でのデータだったため、あまり参考にできないこともわかりました。

バグ修正後の環境で、区切りの長さ(無音待ち時間)をあらためて6段階で試したところ、意外なことに区切りの長さを変えてもセグメント数・翻訳の遅さにほとんど違いが出ませんでした。これは、今回試した講演(3Blue1Brownのよどみなく話し続けるナレーション)ではそもそも無音がほとんど発生しないため、と考えられます。むしろ「無音待ち時間」より「話し続けている場合に強制的に区切るまでの秒数」という別の設定の方が、実際の区切り方に効いている可能性が高いことがわかりました。次はこちらを試すのが良さそうです。

また、これとは別に「どの翻訳AIモデルを使うのがリアルタイム翻訳に向いているか」も5種類のモデルで比較されており、速さ・コスト・精度のバランスが良いモデルへの乗り換えが推奨されています。

## 今後やるべきこと

1. 「話し続けている場合に強制的に区切るまでの秒数」を正式に振り直す実験
2. 事前に専門用語を読み込ませる仕組みが②の聞き間違いを減らせるかを、実際に聞き間違いが起きている難しい区間で再検証すること

どちらも、今の環境(必要な鍵やツールは揃っている)ですぐに着手できる状態です。
